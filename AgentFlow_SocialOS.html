SocialOS Agent Architecture

6 AI agents + 2 sub-agents working in sequence to build your complete social media strategy

🧠
AGENT 1
Brand Manager
Foundation
Ingests and deeply learns all brand information. Crawls website, reads guidelines PDF, builds brand embeddings in vector store. Every downstream agent reads from this knowledge base.
🗂 BrandProfile JSON 🔮 Vector Embeddings
📊
AGENT 2
Analyst
Meta API
Connects to Instagram via Meta Graph API. Fetches all posts, reach, impressions, engagement, comments. Tags content themes, ranks top/bottom performers, detects best posting times. Triggers automatically every 15 days.
✅ What's Working
Top themes, content types with high engagement
❌ What's Not Working
Underperforming topics, dropped pillars
📋 Analyst Report 📈 Performance Snapshot
⚡ Parallel Sub-Agents
🔍
Research Agent
Sub-Agent of Growth Planner
Searches selected platforms simultaneously for trending topics in the brand's niche.
Reddit Google Trends News API Instagram Quora LinkedIn
🕵️
Competitor Tracker
Sub-Agent of Growth Planner
Analyzes up to 5 competitor Instagram accounts. Identifies their top content themes, posting frequency, and — critically — the content gaps they're NOT covering that the brand can own.
📈
AGENT 3
Growth Planner
PPT Output
Synthesizes Analyst data + Research Brief + Competitor Intelligence to define content pillars, content topics, and growth targets for the period. Generates a fully designed, brand-colored PowerPoint strategy deck (15 slides).
📊 Strategy PPT (.pptx) 🎯 Content Pillars
📅
AGENT 4
Strategist
Excel Output
Converts Growth Planner's pillars into a day-by-day content calendar. AI independently decides content format per topic (Reel / Carousel / Graphic / Story) based on what the Analyst says worked, not a fixed ratio.
📋 Content Calendar (.xlsx) 📌 15–30 Day Schedule
✍️
AGENT 5
Copywriter
Script + Captions
Writes everything for every post in the calendar — hook (3 variations), full reel script or slide-by-slide carousel breakdown, captions (short + long), hashtags (20–30), SEO keywords, visual brief. Output in detailed Excel.
📝 Full Content Brief (.xlsx) 🎣 Hook Variations
🎨
AGENT 6
Designer
AI Image Gen
Extracts all Carousel and Graphic posts from the Copywriter's brief. Generates actual visual designs: slide-by-slide carousel images + static graphics — all using the brand's colors, logo, and visual style. Outputs ready-to-download PNG files per post.
🖼 Carousel Slides (per post, all slides)
📸 Static Graphics (1080×1080px)
🎨 Brand-colored overlays + logo watermark
🖼 Carousel PNGs (per slide) 📸 Graphic PNGs 📦 ZIP Download
🔄 15-Day Self-Learning Loop (Automatic)
⏰
Day 15 Trigger
BullMQ cron fires automatically. Analyst re-runs against the past 15 days of actual posts.
📊
Performance Report
What worked vs didn't. Which pillars performed, which to drop, follower growth vs goal.
🧬
Recalibrate & Regenerate
Growth Planner drops failing pillars, doubles winning ones. New PPT + Calendar + Scripts + Designs generated.
📚 Brand Learning Log grows with every cycle — the system gets smarter cumulatively, not just from the latest run
Final Outputs
📊
Strategy PPT
15-slide brand-colored deck with insights, pillars, targets
📋
Content Calendar
15 or 30-day Excel with topic, type, date, pillar per post
📝
Full Brief Excel
Script, hook, caption, hashtags, SEO, visual brief per post
🖼
Designed Assets
All carousel slides + graphics as ready-to-post PNGs
📈
15-Day Report
Performance comparison at each refresh cycle
Screen Wireframes
High-fidelity wireframes for key screens — dark glass morphism aesthetic

Data Flow Between Agents
What data each agent receives, processes, and passes to the next
🧠 Brand Manager
→
Outputs: brand_profile brand_colors brand_voice[] competitors[] knowledge_score vector_embeddings
Reads: Brand Hub DB + Website crawl + Guidelines PDF · Stores embeddings in pgvector
↓
📊 Analyst
→
Receives: brand_profile.instagram_handle meta_access_token
Outputs: analyst_report top_performers[] bottom_performers[] content_type_performance best_posting_times whats_working[] whats_not_working[]
Reads: Meta Graph API (posts, insights, comments) · Stores snapshot in DB with timestamp
↓
🔍 Research Agent
→
research_brief trending_topics[] content_opportunities[]
Sources: Reddit, Google Trends, News API, Quora, Instagram, LinkedIn
🕵️ Competitor Tracker
→
competitor_brief content_gaps[] competitor_themes[]
Up to 5 competitor handles analyzed
↓ (both sub-agents merge here)
📈 Growth Planner
→
Receives: analyst_report research_brief competitor_brief brand_profile learning_log
Outputs: growth_plan content_pillars[] topic_ideas[] follower_target ppt_url
Generates: 15-slide PPTX with brand colors + logo (python-pptx service) · Reads Brand Learning Log for cumulative learning
↓
📅 Strategist
→
Receives: growth_plan content_pillars[] analyst_report.best_posting_times planning_period
Outputs: content_calendar[] posting_schedule content_type_per_topic strategy_xlsx_url
Generates: Color-coded Excel (openpyxl) with 15 or 30 rows, one per post
↓
✍️ Copywriter
→
Receives: content_calendar[] brand_profile brand_voice[] brand_guidelines_chunks
Outputs per post: hook[3] script carousel_slides[] caption_short caption_long hashtags[30] seo_keywords[5] visual_brief copywriter_xlsx_url
↓
🎨 Designer
→
Receives: copywriter_output[carousel_posts] copywriter_output[graphic_posts] brand_colors brand_logo visual_brief[]
Outputs: carousel_slide_pngs[][] graphic_pngs[] zip_download_url design_status_per_post
Uses: DALL-E 3 / Ideogram API for generation · Pillow for brand overlay + logo watermark · S3 for storage
🔄 15-Day Self-Learning Loop — Data Flow
Analyst Re-runs
Pulls new 15-day Instagram data, compares against what was planned
→
Performance Report Generated
Winner/loser pillars identified, follower growth vs goal measured
→
Growth Planner Recalibrates
Drops underperforming topics, scales winning ones. New PPT + Calendar + Scripts + Designs generated.
brand_learning_log updated with cycle learnings → read by Growth Planner in all future runs
